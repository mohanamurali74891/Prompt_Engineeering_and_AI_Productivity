## Template 1: Topic Deep-Dive Research Assistant

```
ROLE: Expert research analyst and academic writer

CONTEXT: I need a comprehensive overview of [TOPIC] for [PURPOSE — study/project/presentation/article].

INSTRUCTIONS:
- Provide a structured research overview
- Cover: Definition, History, Key concepts, Current state, Applications, Future trends
- Include notable researchers/organizations in this field
- Suggest 5 resources to learn more (books, papers, websites)
- Write at [BEGINNER / INTERMEDIATE / EXPERT] level

CONSTRAINTS:
- Stay factual — no speculation unless labeled as such
- If you're uncertain about something, say so explicitly
- Keep total response under 600 words

TOPIC: [TOPIC]
PURPOSE: [PURPOSE]
AUDIENCE LEVEL: [LEVEL]

OUTPUT FORMAT:
## Research Brief: [Topic]

**Definition:** [1–2 sentence definition]

**Background & History:**
[brief timeline of key developments]

**Core Concepts:**
1. [concept 1 — brief explanation]
2. [concept 2]
3. [concept 3]

**Current State (2024–2025):**
[what's happening now]

**Real-World Applications:**
• [application 1]
• [application 2]
• [application 3]

**Future Trends:**
[what's coming next]

**Key Players:**
[notable researchers, companies, organizations]

**Learn More:**
1. [Book/Paper/Website]
2. [Book/Paper/Website]
3. [Book/Paper/Website]
```

## Template 2: Comparative Analysis Generator

```
ROLE: Objective analyst specialized in technology/concept comparison

CONTEXT: Compare [OPTION A] vs [OPTION B] for [USE CASE].

INSTRUCTIONS:
- Create a fair, balanced comparison
- Use a structured table for quick comparison
- Go deep on the most important dimensions for this use case
- Give a clear recommendation with reasoning
- Acknowledge trade-offs honestly

DIMENSIONS TO COMPARE:
[LIST 4–6 dimensions, e.g., Performance, Cost, Ease of use, Scalability]

OPTION A: [NAME]
OPTION B: [NAME]  
USE CASE: [SPECIFIC USE CASE]
MY CONSTRAINTS: [budget/skill level/team size/etc.]

OUTPUT FORMAT:
## [Option A] vs [Option B]: Comparison for [Use Case]

### Quick Comparison Table
| Dimension | [Option A] | [Option B] | Winner |
|-----------|------------|------------|--------|
| [dimension] | [rating] | [rating] | [A/B/Tie] |

### Deep Dive

**[Option A]**
✅ Strengths: [list]
❌ Weaknesses: [list]

**[Option B]**
✅ Strengths: [list]
❌ Weaknesses: [list]

### 🏆 Recommendation
For [your use case], I recommend **[Option]** because [reasoning].

**The exception:** If [condition], then [other option] is better.
```

## Template 3: Literature Review Assistant

```
ROLE: Academic research assistant specialized in systematic literature reviews

CONTEXT: Help me organize and synthesize research on [TOPIC].

INSTRUCTIONS:
- Identify key themes across the research
- Note areas of consensus vs. debate
- Highlight landmark papers/findings
- Point out research gaps
- Suggest research questions for further study

PAPERS/SOURCES PROVIDED:
[PASTE ABSTRACTS OR KEY POINTS FROM YOUR SOURCES]

RESEARCH QUESTION: [YOUR RESEARCH QUESTION]

OUTPUT FORMAT:
## Literature Review: [Topic]

**Research Question:** [question]

**Themes Identified:**
1. [Theme 1]
   - Evidence: [papers/findings]
2. [Theme 2]
   - Evidence: [papers/findings]

**Consensus:** [what most sources agree on]

**Debates/Contradictions:**
• [point of disagreement — Source A says X, Source B says Y]

**Landmark Findings:**
• [key finding 1]

**Research Gaps:**
• [gap 1 — no one has studied X]
• [gap 2]

**Suggested Research Questions:**
1. [question 1]
2. [question 2]
```

## Template 4: Concept Explainer (Feynman Technique)

```
ROLE: World-class teacher who can explain any concept simply

CONTEXT: Explain [CONCEPT] using the Feynman Technique — explain it so simply that a [TARGET AUDIENCE] could understand it.

INSTRUCTIONS:
- Start with a real-world analogy
- Break down to first principles
- Use simple language (avoid jargon, or explain it when used)
- Include a visual description or ASCII diagram if helpful
- End with a quiz question to test understanding

CONCEPT: [CONCEPT]
TARGET AUDIENCE: [12-year-old / college freshman / non-technical manager / etc.]
DEPTH REQUIRED: [Surface level / Moderate / Deep dive]

OUTPUT FORMAT:
## Explaining [Concept] Simply

**The Analogy:**
[Real-world comparison that makes it click]

**The Simple Explanation:**
[Plain language explanation, step by step]

**Going Deeper:**
[For those who want more detail]

**Visual:**
```
[ASCII diagram or description]
```

**Common Misconceptions:**
❌ [wrong belief] → ✅ [correct understanding]

**Test Your Understanding:**
[1 question to check comprehension]
[Answer revealed below]
```

## Template 5: Trend Analysis Prompt

```
ROLE: Industry analyst and technology futurist

CONTEXT: Analyze current trends in [INDUSTRY/DOMAIN] for [YEAR].

INSTRUCTIONS:
- Identify 5 major trends
- For each trend: Current state, Driving forces, Impact, Timeline
- Identify risks and opportunities
- Provide a strategic insight for [YOUR ROLE/ORGANIZATION]

DOMAIN: [INDUSTRY/TECHNOLOGY AREA]
YOUR ROLE: [Student / Startup / Enterprise / Researcher]
TIME HORIZON: [Next 1 year / 3 years / 5 years]

OUTPUT FORMAT:
## Trend Analysis: [Domain] — [Year]

### Trend 1: [Name]
**What:** [brief description]  
**Why Now:** [driving forces]  
**Impact:** High / Medium / Low  
**Timeline:** [when it peaks]

[repeat for 5 trends]

### Opportunities for [Your Role]
• [opportunity 1]
• [opportunity 2]

### Risks to Watch
⚠️ [risk 1]
⚠️ [risk 2]

### Strategic Recommendation
[2–3 sentence actionable insight]
```
