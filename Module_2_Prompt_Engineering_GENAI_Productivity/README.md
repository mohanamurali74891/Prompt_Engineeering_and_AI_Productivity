> **Codomax Gen AI Internship — Day 6 to Day 10**

## 📌 Overview

This module covers the fundamentals and advanced techniques of Prompt Engineering, and culminates in building a reusable **AI Productivity Toolkit** — a collection of structured prompt workflows for real-world tasks.

---

## 🎯 Learning Objectives

| Topic | Description |
|-------|-------------|
| Zero-shot Prompting | Asking the model directly without examples |
| Few-shot Prompting | Providing examples to guide model behavior |
| Roles & Contexts | Setting up personas and situational context |
| Instructions & Constraints | Controlling output format and length |
| Structured Outputs | Getting JSON, tables, bullet lists from AI |
| Summarization Prompts | Condensing documents and articles |
| Classification Prompts | Categorizing text into labels |
| Generation Prompts | Creative and factual content generation |
| AI-Assisted Coding | Using AI to write and debug code |
| Prompt Evaluation | Scoring and testing prompts systematically |
| Reusable Templates | Building a personal prompt library |
| AI Productivity Toolkit | End-to-end workflow automation |
